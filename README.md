# Meta Ads → Google Sheets

Скрипт, який щодня вивантажує показники з рекламних кабінетів **Meta Ads** у **Google Sheets**. Підтримує кілька кабінетів і кілька таблиць, сам створює лист нового місяця та донаповнює пропущені дні. Замінює ручне перенесення статистики з Ads Manager.

## Можливості

- **Кілька кабінетів, кілька таблиць.** Кожен рекламний кабінет пишеться у власну Google-таблицю.
- **Кілька послуг в одному кабінеті.** Кампанії розподіляються між таблицями за ключовими словами в назві; частину можна відправити в "решту" (`is_catch_all`). До Meta API за день надсилається один запит на кабінет.
- **Метрики за день:** витрати, кількість заявок, CPM (зважений: витрати / покази × 1000), охоплення, кліки по посиланню, усі кліки.
- **Тип заявок визначається автоматично:** за ціллю кампанії (покупки, повідомлення, ліди), а для старих кампаній за ключовими словами в назві. Для окремих кабінетів можна задати власну конверсію.
- **Актуалізація заднім числом.** Meta донараховує конверсії протягом кількох днів, тому щодня перезаписуються останні кілька днів (за замовчуванням 3).
- **Автоматичний лист нового місяця.** Скрипт дублює лист попереднього місяця зі збереженням формул і форматування, підганяє кількість рядків під довжину місяця й очищає лише власні колонки.
- **Backfill.** Ручний режим, що заповнює порожні дні за будь-який місяць для всіх або одного кабінету.
- **Колонки з формулами та ручними даними не змінюються.**

## Стек

- Python 3
- [facebook-business](https://github.com/facebook/facebook-python-business-sdk): Meta Marketing API
- [gspread](https://docs.gspread.org/) і google-auth: Google Sheets API

## Встановлення

Потрібен Python 3.10 або новіший.

```bash
git clone https://github.com/Arkysht/meta_script.git
cd meta_script
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Налаштування

### 1. Доступ до Google Sheets

1. Створіть сервісний акаунт у Google Cloud, увімкніть Google Sheets API та Google Drive API.
2. Завантажте JSON-ключ сервісного акаунта.
3. Відкрийте кожну таблицю й надайте сервісному акаунту (його email) доступ **редактора**.

### 2. Токени: `config.py`

Скопіюйте `config_example.py` у `config.py`:

```python
FB_APP_ID = "YOUR_FB_APP_ID"
FB_APP_SECRET = "YOUR_FB_APP_SECRET"
FB_ACCESS_TOKEN = "YOUR_FB_ACCESS_TOKEN"
GOOGLE_SERVICE_ACCOUNT_FILE = "service_account.json"
```

### 3. Кабінети: `accounts_config.py`

Скопіюйте `accounts_config_example.py` у `accounts_config.py`.

Простий кабінет (одна таблиця):

```python
ACCOUNTS = [
    {
        "name": "Example Shop",
        "fb_account_id": "act_1234567890",
        "spreadsheet_id": "YOUR_SPREADSHEET_ID",
    },
]
```

Кабінет із кількома послугами (різні таблиці, розподіл за назвою кампанії):

```python
ACCOUNTS = [
    {
        "name": "Example Studio",
        "fb_account_id": "act_0987654321",
        "services": [
            {"name": "Service A", "spreadsheet_id": "SHEET_ID_A", "keywords": ["service_a", "сервіс а"]},
            {"name": "Other", "spreadsheet_id": "SHEET_ID_B", "is_catch_all": True},
        ],
    },
]
```

Необов'язкові параметри кабінету або послуги:

| Параметр | Призначення |
|---|---|
| `column_map` | Свої літери колонок замість стандартних |
| `header_row` | Рядок із заголовками (за замовчуванням 1) |
| `custom_requests_action_type` | Рахувати "заявками" одну конкретну подію Meta замість автоматичної класифікації |

## Структура таблиці

- Дані лежать на листі з назвою `MM.YYYY` (наприклад, `07.2026`).
- Рядок дня фіксований: день 15 → рядок `header_row + 15`.
- Перший лист місяця потрібно створити вручну з потрібною структурою. Далі скрипт дублює його сам.

Стандартні колонки, які заповнює скрипт:

| Колонка | Значення |
|---|---|
| A | Дата |
| B | Витрати |
| C | Кількість заявок |
| K | CPM |
| L | Охоплення |
| M | Кліки по посиланню |
| N | Усі кліки |

Решта колонок (формули, ручні дані) не змінюється.

## Класифікація кампаній

| Тип | За ціллю кампанії | Запасний варіант: слова в назві |
|---|---|---|
| Покупки | `OUTCOME_SALES` | `purchase` |
| Повідомлення | `OUTCOME_ENGAGEMENT` + `REPLIES` / `CONVERSATIONS` | `direct`, `директ`, `смс`, `sms`, `повідомлення` |
| Ліди | `OUTCOME_LEADS` | `lead`, `лид`, `квиз`, `quiz` |

Кампанії, тип яких визначити не вдалося, потрапляють у лог із попередженням.

## Запуск

```bash
# звичайний режим: оновлює останні дні для всіх кабінетів
python meta_ads_to_sheets.py

# заповнити порожні дні поточного місяця (з 1-го числа по вчора)
python meta_ads_to_sheets.py --backfill-month

# за конкретний місяць і кабінет
python meta_ads_to_sheets.py --month 07 --account act_1234567890
```

Формати місяця: `07`, `7`, `07.2026`, `2026-07`.

### Запуск за розкладом

Скрипт відпрацьовує й завершується, тому підходить для cron або systemd timer.

Приклад для cron (щодня о 08:00):

```
0 8 * * * cd /path/to/meta_script && ./venv/bin/python meta_ads_to_sheets.py
```

## Безпека

- `config.py`, `accounts_config.py` та JSON-ключ сервісного акаунта не потрапляють у git (див. `.gitignore`).
- ID таблиць і кабінетів клієнтів зберігайте лише в `accounts_config.py`.
